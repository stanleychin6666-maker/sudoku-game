# 數獨遊戲第六階段（由第五階段增量開發）

開啟 index.html（Chrome/Edge）即可遊玩；保留第五階段所有功能。若瀏覽器限制 file:// 下的 localStorage，可透過 VS Code Live Server 或 `python -m http.server 8000` 開啟 http://localhost:8000/ 。

## 新增功能
- 個人成績：每次真正通關才登錄一次，依遊戲 ID 去重；統計總完成場次、分難度最快與平均、累計錯誤與提示、最近十場。資料儲存於 `sudoku-stage6-stats-v1`。
- 每日挑戰：以 Asia/Taipei 日期（YYYY-MM-DD）為基準，使用日期派生的固定亂數產生中等難度、固定 40 空格的唯一解題目。同日期產生相同題目；不可對當日挑戰重複領取成績。使用 `sudoku-stage6-meta-v1` 保存遊戲 ID/模式。這是本機模式，修改電腦時間或 localStorage 仍可能影響紀錄，不具防作弊功能。
- 本機排行榜：每個難度分開，先按總秒數，其次錯誤次數，最後提示次數升冪排序，只包含已通關紀錄。
- 介面：淺／深色模式、同行同列同宮格強調、相同數字高亮（可關閉）、3×3 筆記小格與響應式數字鍵盤。

## 原有功能與變動邊界
- `sudoku.js` 的數獨規則、挖空後的每步唯一解驗證、解題算法均保留。只把內部亂數來源改為可暫時注入的 `sudokuRandom`，每日生成後立即恢復。
- `game-state.js` 與原有 `test.js`、`test-stage5.js` 不修改。
- `stage6.js` 新增日期、固定種子、成績／排行榜／連續天數函式。
- `index.html` 新增頁面、樣式與呼叫；`test-stage6.js` 新增測試；`run-tests.js` 加入回歸測試。

## 測試
Node.js 執行 `node run-tests.js`。本次 Node.js 執行：舊有 300 題 + 10 衝突 + 6 開關 + 14 筆記／提示 + 24 遊戲狀態 + 1 非法已知數字 + 新增 14 項 = 369 項，全部通過。瀏覽器端到端自動化測試未成功執行（執行環境封鎖頁面導覽），手機真機及平板尚未驗證。

## 手動驗收
1. 選擇簡單／中等／困難開始遊戲，測試輸入、筆記、唯一解、提示、衝突開關、計時、暫停、撤銷／重做、錯誤上限、刷新恢復。
2. 切換深色模式，選格確認同行、同列、同宮格高亮；開關相同數字高亮，確認仍可正常填答。
3. 選每日挑戰，記下題目並刷新，題目與進度應一致。另一個相同日期的無存檔環境中，題目也應一致。
4. 在測試用資料或完成一局之後，開啟個人成績和排行榜，檢查時間與錯誤、提示統計。重新整理後統計不可消失；通關後刷新不可新增一場。
5. 完成每日挑戰後再按每日挑戰，應告知已完成；隔日應有新題，連續完成天數應更新。
6. 開啟手機裝置模擬器，測試 320/375/390/768 px 寬度不應水平捲動，九宮格維持正方形、數字按鈕可點；請再於真機檢查。

提醒：排行榜是本機紀錄，不是公開的玩家競賽服務；localStorage 可以自行修改。本機成績沒有防作弊或跨裝置同步功能。
